# Página de Presentación — Desarrollador Web

Sitio web personal diseñado para presentar mi perfil como desarrollador web, mis habilidades técnicas, proyectos destacados y canales de contacto. Construido con un enfoque *mobile-first* y estilizado con **Tailwind CSS**.

> **Estado del proyecto:** En desarrollo activo — actualizando secciones, proyectos y optimizaciones de interfaz.

## Vista previa y enlace

- **Demo en vivo:** `[https://tu-usuario.github.io/my-profile/]`
- **Repositorio:** `[https://github.com/CrlsMenz/my-profile]`

## Características principales

- **Diseño responsivo:** Adaptado a pantallas móviles, tablets y escritorio utilizando las utilidades de **Tailwind CSS**.
- **Estructura clara:** Secciones enfocadas en presentación profesional, stack tecnológico, proyectos y contacto.
- **Mantenibilidad:** Clases utilitarias y estructura de carpetas organizada para facilitar ajustes rápidos y escalabilidad.

## Tecnologías utilizadas

- **HTML5** — Estructura semántica y accesibilidad básica.
- **Tailwind CSS** — Diseño de interfaz, espaciado, tipografía y diseño responsivo.
- **JavaScript** — Interactividad y comportamientos dinámicos de la página.
- **Git & GitHub** — Control de versiones y despliegue.
